# Cloud-Native Network Telemetry & Data Pipeline.
## Log Netwkorking dan Access List Networking
Membuat script code di dengan menggunakan codespace untuk membuat simulasi log data networking dari penggunaan bandwidth, source ip, latency, timestamp. Dengan menggunakan port 5000 dengan menggunakan API Telemetry.
Dengan keamanan menggunakan Access List (ACL) untuk menghubungkan dari alamat Device yang ingin dituju dan juga dengan menggunakan Secret API Key untuk mengakses URL tersebut.
